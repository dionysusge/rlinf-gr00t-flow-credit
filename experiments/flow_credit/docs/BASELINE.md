# Baseline

This repository was initialized from the server-side RLinf source tree used for
the GR00T N1.7 + LIBERO-Spatial Flow-SDE PPO experiments.

## Source baseline

- Framework: RLinf
- RLinf release line: v0.3
- Recorded upstream baseline commit: `0505431`
- Policy: NVIDIA GR00T N1.7
- Benchmark: LIBERO-Spatial
- RL method: Flow-SDE PPO
- Embodiment tag: `libero_sim`
- Action horizon: 16
- Action dimension: 7

The original upstream Git history was not retained in this repository. This
repository starts with a snapshot of the validated server-side implementation.
